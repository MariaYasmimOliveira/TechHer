# TechHer: Vitrine de Talentos e Curadoria de Oportunidades

---

## 🎯 Sobre o Projeto

**TechHer** é um projeto de extensão universitária vinculado à disciplina de **Tópicos Interdisciplinares III**. Ele funciona como uma plataforma de inclusão voltada para mulheres estudantes de tecnologia e desenvolvedoras, com foco especial em diversidade.

---

## 🚀 Objetivos

**Mínimo Produto Viável (MVP)**: Desenvolver uma plataforma de impacto social para vitrine de portfólios e agregação de vagas.

**Inclusão Digital**: Validar a eficácia da acessibilidade web (WCAG) como ferramenta de inclusão.

**Produção Científica**: Elaboração de um artigo científico focado em desenvolvimento acessível para submissão.

---

## 🛠️ Tecnologias e Metodologia

O desenvolvimento utiliza ferramentas que priorizam a agilidade e a conformidade técnica:

**Frontend**: Next.js e Tailwind CSS.

**Gestão de Dados**: Google Sheets API (via Sheety) para automação sem backend complexo.

**Auditoria de Acessibilidade**: Uso de Lighthouse e Axe DevTools para garantir conformidade com **WCAG 2.1**.

---

## 📅 Cronograma de Atividades

O projeto possui uma duração total de 9 semanas para a fase piloto acadêmica:

**Fase 1 (Semanas 1-2)**: Definição da arquitetura e estruturação técnica com Google Sheets.

**Fase 2 (Semanas 3-5)**: Desenvolvimento da vitrine de portfólios e sprint de acessibilidade (ARIA labels e contraste).

**Fase 3 (Semanas 6-7)**: Testes com usuárias convidadas e ajustes de performance.

**Fase 4 (Semanas 8-9)**: Redação do relatório de extensão.
